Key bindings

Keys work anywhere on this page, and the text box in Keys mode uses the same bindings. Click + on an action, then press the key to give it. Bindings are kept in this browser.

A key is remembered by its position on the keyboard, as games do, so WASD stays a cluster on any layout (Neo2, AZERTY...). It is shown as what it prints on your keyboard once you have pressed it; until then (in italics) as it would print on a US keyboard. Arrows, Enter, Esc, Tab and Backspace are remembered by name, so a layer that produces them from other keys works too.
